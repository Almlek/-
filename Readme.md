# مُحضِّر الذكي — منصة تحضير الدروس بالذكاء الاصطناعي

منصة متكاملة لتحضير الدروس المدرسية باستخدام الذكاء الاصطناعي، صُممت خصيصاً للمعلمين في العالم العربي.

## المميزات

- 🧠 توليد تحضير كامل بالذكاء الاصطناعي في أقل من دقيقة.
- 📊 جودة تربوية وفق تصنيف بلوم للأهداف.
- 🖨️ ورقة تحضير دقيقة بحجم A4 جاهزة للطباعة.
- 🌐 واجهة عربية RTL بالكامل، متجاوبة مع الجوال.
- 🔐 أمان كامل — المفاتيح السرية لا تخرج من الخادم.
